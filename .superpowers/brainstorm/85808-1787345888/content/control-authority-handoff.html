Control Authority Handoff

The lead ship carries the player/tether, but Fleet C2 can still pilot it until the operator explicitly takes manual control.

Lead Ship Authority Model
Player suit/cockpit is on lead ship
Fleet C2 app issues squad orders
Lead ship PB receiver applies tiny commands
Manual takeover toggles autonomous mode off
C2 continues escort/other-ship control if allowed
Autonomous Mode On
Remote Control/autopilot receives C2 waypoints
C2 may orient rail geometry and manage combat posture
PB receiver accepts current bridge commands
Cockpit pilot is present but not directly flying
Manual Override
Operator runs PB argument: c2 off / c2 toggle
Receiver stops applying movement/fire-posture commands
Remote Control/autopilot is disabled or released
UI marks lead ship Manual while squad context remains visible

Safety Default

Manual override should fail closed: once autonomous mode is off, Fleet C2 can observe and plan but cannot actuate that ship until the operator toggles it back on.
