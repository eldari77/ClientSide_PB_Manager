Fleet C2 Registration Flow

The app owns fleet intent. The in-game shims prove each ship can actually participate. Discovery produces an operator checklist before any squad is marked ready.

Proposed V1 Flow
1. Create bridge in Fleet C2 app
2. Assign C2 module + ship role/class
3. Paste generated shim/CustomData on ship PB
4. Run discovery while ship is visible
5. Review readiness actions
Discovery Should Confirm
Receiver PB heartbeat and matching bridge id
Remote Control block found and usable
Gyros/thrusters available for vanilla autopilot/corrections
Fixed rail weapon group found
WeaponCore power targeting configured
PDC group present but default posture avoids 3 km range
Telemetry exposes enough target/No Pwr data, or fallback manual control is needed
Readiness Summary Shape
Ready: bridge, role, Remote Control, rail group
Warn: WeaponCore No Pwr telemetry not proven
Blocker: no receiver heartbeat / bad bridge id
Action: paste CustomData, rename group, set WC power targeting

Open Choice

Should Fleet C2 allow a ship into a squad with warnings, or should any missing discovery item block squad readiness until acknowledged?
