Receiver Failover State

Each ship is one logical C2 unit with a primary receiver and optional standby receiver. Only one should actuate at a time.

Primary Active

Failover Rules
Do not fail over on one missed tick
Probe primary with a cheap status/nonce request
Promote backup only after consecutive stale/failed evidence
Mark failover reason in Fleet C2 UI
Return Rules
Primary must show fresh heartbeat and matching bridge id
Primary must acknowledge observe/probe before actuation resumes
Backup demotes to standby before primary applies commands
Never allow primary and backup to actuate simultaneously
