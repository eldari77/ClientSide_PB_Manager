Target Priority Model

Fleet C2 should use WeaponCore lock-on as the operator's target intent when available, then rotate targets when the current hostile is disabled.

V1 Target Decision Chain
1. Read WeaponCore locked target, if exposed
2. Hold squad focus on locked hostile
3. Watch for No Pwr / disabled state
4. Retire disabled target for salvage
5. Fallback to nearest powered hostile
Primary Path
Operator locks target in-game through WeaponCore
Plugin surfaces locked target identity/range/status
Fleet C2 keeps frigates/corvettes on that target
Power-targeting remains ship prep, not a dynamic order
Fallback Path
If lock telemetry is missing, use Fleet C2 manual target selection
If No Pwr telemetry is missing, operator can mark disabled
If contact ranking is missing, stay on manual target until changed
Never keep firing a known disabled ship by default
