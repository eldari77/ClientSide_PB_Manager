Combat Envelope And Roles

V1 should treat combat as doctrine-driven positioning first, not dogfighting. The client planner keeps the squad near the rail envelope and avoids the PDC danger band unless explicitly ordered.

Engagement Bands
200-300 km: main-drive sensor visibility
10 km: fixed rail max range
8-8.5 km: preferred rail fighting band
3 km: PDC danger band, avoid by default
Disengage: max burn along current vector until 200 km+, then reduce signature
Basic V1 Combat Roles
Rail Frigate: hold side-angle rail solution, target power, avoid overclosing
Escort Corvette: screen frigates, avoid PDC range, intercept threats if supported
Pursuit: maintain rail band, chase only while geometry is favorable
Guard: orbit/offset around protected ship and bias guns outward
Disengage: burn vector, then coast/low-thrust after contact break

Core Unknown

Power-first targeting depends on what data we can legally observe. The framework can always accept a human-designated target, but automatic subsystem targeting needs either WeaponCore-accessible target data, visible block data, or a manually learned ship profile.
