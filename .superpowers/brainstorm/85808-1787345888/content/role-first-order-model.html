Role-First Fleet Model

A ship's class/core defines what it is good at. Orders change what it is trying to do right now.

Decision Stack
Core / Class Block: authoritative class, orientation, limits
↓
Role: rail frigate, escort corvette, command ship, etc.
↓
Order: patrol, guard, pursue, disengage, hold fire, regroup
↓
Doctrine Parameters: rail band, side-angle, screen offset, thrust signature
↓
Tiny Receiver Commands: Remote Control waypoint, block toggles, fire posture
Rail Frigate Defaults
Preferred band: 8-8.5 km
Avoid: PDC range below 3 km
Orientation: side-angle rail solution from core frame
Default target posture: WeaponCore power targeting
On disabled target: cycle to next hostile
Escort Corvette Defaults
Preferred position: screen/offset around protected ship
Threat response: intercept or bias toward torp vector if supported
Avoid: independent overextension into PDC range
Movement: keep up with frigate or command ship
Fallback: regroup if command geometry is stale
