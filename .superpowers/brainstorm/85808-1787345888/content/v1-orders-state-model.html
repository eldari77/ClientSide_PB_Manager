V1 Order Set

The Fleet C2 app should expose six basic orders. Roles interpret each order differently, while the receiver PB only sees tiny actuation packets.

Orders
Patrol
move between points, scan/hold doctrine
Guard
protect ship/area, maintain screen geometry
Pursue
close/maintain rail envelope on target
Hold Formation
keep assigned offsets and facing
Regroup
return to anchor/leader safely
Disengage
burn out along vector, then reduce signature
Normal Transitions
Patrol → Pursue when hostile target is selected
Guard → Hold Formation when threat is stale
Pursue → Regroup if range/geometry goes bad
Any order → Disengage on explicit operator command
Role Interpretation
Frigate Pursue: rail band, side-angle, power target
Corvette Guard: PDC screen, single-rail contribution
Frigate Disengage: max burn vector, then coast/low thrust
Corvette Regroup: recover screen position around anchor
