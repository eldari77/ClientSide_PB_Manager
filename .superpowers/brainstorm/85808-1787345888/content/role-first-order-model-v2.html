Role-First Fleet Model

Roles are stable ship identities. Orders change the current intent, but each role interprets the same order through its own doctrine.

Rail Frigate
Primary job: fixed-rail damage from standoff range
Preferred band: 8-8.5 km inside 10 km rail max
Avoid: PDC range below 3 km
Geometry: side-angle rail solution from core frame
Targeting: WeaponCore power targeting by default
Target cycling: move on when No Pwr / disabled is detected
Escort Corvette
Primary job: PDC close-in defense and torpedo interception
Secondary job: single-rail standoff contribution
Preferred band: generally match fleet rail distance
Geometry: orient toward hostile grid while preserving screen position
Avoid: chasing into hostile PDC range or overextending from protected ships
Fallback: regroup if screen geometry or contact data goes stale
